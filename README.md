## The entry

> My Roomba unionized. Now it only cleans the rooms it believes in.

## How it works

`main.py` (Python 3, stdlib only) writes the single joke above to `entry.txt`
— 65 characters, inside the 1–140 character gate. It writes to
`MAKEFUN_OUTPUT_DIR` when set (the grader sandbox), falling back to the
script's own directory.

Run it:

```sh
python3 main.py
```
